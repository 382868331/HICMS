HICMS 软件开发计划

一、项目概述

HICMS（信息中心会议综合管理系统）是一套会议预定与日常办公与协作的多端一体化平台，覆盖 Web 页面端、微信小程序端、Android 端及 HarmonyOS 端，后端采用通用 Java 接口架构，支持高并发场景。

四、技术架构

4.1 多端支持

端技术栈适配范围
Web 页面端响应式前端框架电脑、平板、折叠屏手机、竖屏手机
微信小程序端微信小程序原生 / Taro微信生态内运行
Android 端Android 原生 / FlutterAndroid 手机及平板
HarmonyOS 端ArkTS / ArkUI鸿蒙手机及平板
后端Java 通用接口统一 API，支持高并发

4.2 后端架构

  • 语言：Java
  • 架构：微服务 / 模块化单体
  • 特性：通用接口设计、接口并发支持、统一认证鉴权、API 版本管理

五、功能模块

5.1 会议功能

  • 查询会议室列表及概况（容纳人数、设备、位置、占用状态）
  • 预定会议（时间、会议室、参会人员、主题）
  • 取消会议（权限校验、通知参会人）
  • 会议提醒（会前通知）

5.2 通讯录功能

  • 查询今日信息中心负责人及值班人
  • 查询今日机要局负责人及值班人
  • 查询值班人员总表（按日期、科室筛选）
  • 发送短信
  • 拨打数字电话
  • 发送微信小程序通知（需用户关注小程序并授权）
  • 发送邮件

5.3 AI 助手功能

  • AI 查询个人预定会议数据，生成个人会议分析报告
  • AI 音频分析（会议录音转文字、摘要提取）
  • AI 文件知识库（支持 PDF、TXT、Word、Excel 等办公文档的智能检索与问答）
  • 高级 AI 多模态模型对话（文本、图片、文件综合理解）

5.4 管理中心

  • 会议管理：会议室维护、会议审批、会议统计
  • 人员管理：组织架构、人员信息、角色权限
  • 值班表管理：值班编排、班次模板、自动排班
  • AI 助手管理：模型配置、知识库管理、对话记录
  • 数据管理：数据备份、数据导出、日志查询
  • 公告与消息管理：公告发布、消息推送、已读追踪
  • 通讯管理：短信模板、邮件模板、通知渠道配置

5.5 通知功能

  • WebSocket 实时消息推送
  • 短信通知
  • 数字电话通知
  • 微信小程序通知（需用户关注小程序并授权）
  • 邮件通知
  • 通知渠道优先级与降级策略

5.6 个人信息功能

  • 头像更换
  • 用户名修改
  • 手机号绑定 / 修改
  • 邮箱绑定 / 修改
  • 微信号绑定 / 修改
  • 所处科室信息
  • 密码修改

5.7 埋点与数据分析

  • 全量用户操作记录（点击、提交、跳转、搜索等）
  • 页面留存时间统计
  • 用户行为路径分析
  • 数据上报与可视化看板

5.8 安全

  • SQL 注入防护
  • XSS 跨站脚本防护
  • CSRF 跨站请求伪造防护
  • 接口鉴权与权限控制（RBAC）
  • 敏感数据加密存储
  • 操作日志审计
  • 登录安全策略（失败锁定、验证码、多因素认证）

十、风险管理

风险项影响应对措施
多端并行开发资源不足进度延期优先核心端，逐步扩展
小程序通知授权率低触达率不足短信 / 邮件作为兜底通道
AI 模型调用成本高预算超支本地模型 + 云端模型混合部署
高并发场景性能瓶颈系统不可用提前压测、弹性扩容、限流降级
本文档为总体规划，具体细节在各阶段执行中逐步细化。
